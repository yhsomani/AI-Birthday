## 2024-05-24 - Add Haptic Feedback to Primary Interactive Elements
**Learning:** Subtle physical feedback (haptics) on primary actions, like a FloatingActionButton, improves user engagement and makes the interaction feel more responsive.
**Action:** Use `HapticFeedback.lightImpact()` (requires importing `package:flutter/services.dart`) within the `onPressed` handler for main interactive elements.
