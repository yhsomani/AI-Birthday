## 2026-07-18 - Disabling input fields during execution\n**Learning:** In React Native `TextInput` components, using `editable={false}` correctly disables the field from user interaction, and pairing it with `accessibilityState={{ disabled: true }}` ensures screen readers announce the state change properly during async loading states.\n**Action:** Use this pattern whenever forms or command inputs should be blocked while a process (like 'running') is in progress.
