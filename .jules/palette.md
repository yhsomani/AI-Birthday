## 2024-05-23 - Add haptic feedback to primary interactive elements
**Learning:** Providing subtle physical feedback using `HapticFeedback.lightImpact()` on primary interactive elements (like a `FloatingActionButton`) makes the micro-interaction feel more responsive and improves the overall tactile experience.
**Action:** Always consider adding haptic feedback to main interaction points to provide immediate, satisfying tactile confirmation to the user.
