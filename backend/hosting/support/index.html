Clear help without private message content

Start with the explanation below. If you still need help, use only the verified support link; never send a password, access token, full contact list, or birthday message.

Android did not send

Open Home and review every readiness item: supported install channel, SMS permission, active approved SIM, Google account, recent Contacts sync, background restriction, battery optimization, unused-app restriction, Data Saver, Low Power Standby, test receipt, and online coordination. A missed delivery window is not sent late.

iPhone reminder or composer

Notification permission and Focus can hide or delay reminders. Birthday Autopilot never sends in the background on iPhone. Open the app, review the current proposal, then use Apple’s editable composer and tap Send yourself. If Android manages this account, iPhone composer actions remain suppressed for safety.

Status is Unknown

Unknown means the app lacks reliable evidence. Do not resend blindly. Android may refine the status if a valid system callback arrives. On iPhone, a lost MessageUI result also remains unknown and the app does not reopen automatically.

Account and data controls are different

  • Disconnect Contacts removes app-derived contact data and future related work, but keeps the Google grant.
  • Revoke Google access removes every OAuth scope this Google account granted to Birthday Autopilot, not only Contacts.
  • Local wipe removes app-owned data from one device and cancels its work or reminders. It does not delete the online Firebase account or external messages.
  • Delete account removes the Firebase account and associated app-operated server records through the protected deletion saga. Use the public deletion page if the app is unavailable.

Use the verified support workflow above. What to include in a support request

Include the platform, app version, a plain description, and a content-free error code or deletion receipt reference if shown. Do not include names, phone numbers, birthdays, message text, contact identifiers, prompts, passwords, access tokens, private keys, or screenshots containing them.
