# Product Scope and Non-Goals

## Candidate approved core

DOM-01 Entry, DOM-02 People, DOM-03 Birthday, DOM-04 Planning, DOM-05 Reminders, DOM-06 Manual Studio, DOM-07 optional entitled AI, DOM-08 handoff/history, DOM-09 account/entitlement, and the local portions of DOM-10 privacy/continuity. Owner approval remains `DA` for this exercise.

## Conditional

Cloud backup production, Nano, public legal/support site, automated SMS, auto-preparation, additional locales/platforms and any orchestration control plane.

## Explicit non-goals (`DR` unless separately approved)

Autonomous WhatsApp; bulk/campaign sending; public profiles/social network; CRM or collaboration; contact/message scraping; general chat; multi-user/team tenancy; unrequested calendar/email/social integrations; private-content analytics; backend AI proxy by default.

## Conflicting public/product scope

Birthday Autopilot is in AI-Birthday scope. Its existing server control plane is a separate deployment boundary; the public Hosting identity, legal/support ownership, and release remain unresolved and require separate approval.
