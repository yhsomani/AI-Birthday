# Product Principles

This is the authoritative principle summary; see [vision](vision-and-mission.md).

- Prefer user decisions for send, consent and destructive operations.
- Treat all imported/external data as untrusted and all provider state as capability, not truth.
- Use stable IDs and explicit state transitions for occurrences, drafts, events and jobs.
- Preserve manual completion paths; degrade gracefully.
- Minimize data at every boundary; do not put secrets or private prompt material into analytics/logging.
- Keep local, account, cloud, provider, store and delivery truth distinct.
- No invisible automatic message, billing or data replication.
- Accessibility and privacy are release gates, not post-release polish.
