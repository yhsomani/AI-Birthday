# Implementation Readiness

## Ready for implementation planning

Product identity and core value loop; People/Birthday/Studio/manual delivery domain boundaries; local-first architecture direction; entitlement-first AI policy; target testing and operational gates. These are proposed/approved-intent baselines, not authorization.

## Not ready

Destructive Person/Birthday schema migration; per-cycle history conversion; backup retention/restore/deletion; account switching/local ownership; paid AI packaging; public Autopilot/Hosting; auto-SMS/auto-prepare; iOS/locales; numerical SLO/capacity; production deployment. Each is blocked by decisions, data inventory or external evidence.

Before implementation, link the exact FR/BR/AC/TC set to a delivery epic and obtain the named approver. Preserve legacy behavior until migration/rollback evidence is accepted.
