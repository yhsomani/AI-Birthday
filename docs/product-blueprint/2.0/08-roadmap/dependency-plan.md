# Dependency Plan

Critical path:

`Product approval → account/data ownership → aggregate and identity ADR → migration evidence → core workflows → delivery truth → entitlement/privacy contracts → end-to-end/device/security evidence → release configuration → operational readiness → release`

Parallel after contracts: UX/a11y and CI/observability foundation; backend identity/entitlement environment preparation; documentation governance. Gated branches: Autopilot integration/deployment and automatic-SMS activation require security, policy, device and deployment evidence; auto-prepare, public Hosting identity/SLA, iOS/locales and bidirectional sync remain decision-gated.
