# Risk Register

RSK-001–RSK-013 are authoritative in [governance risks](../01-governance/risks-register.md). High/high items: backup generation retention; incomplete local deletion; product identity conflict (Hosting/Autopilot); import/aggregate ownership; birthday identity/history; unsupported operational/public claims. Each requires owner, approved mitigation, validation evidence and release disposition. Acceptance of a risk is separate from resolving a requirement conflict.
