# Decision Register (2.0 Approval Queue)

DEC-036–DEC-047 are defined in [governance decisions](../01-governance/decisions-register.md). All are `DA`. They must be closed with: exact wording, decision owner/approver, date, alternatives, consequence, evidence, affected requirements and implementation/release conditions. Existing DEC-001–035 remain preserved historical/detail decisions; no new implied approval is asserted.

Approval order: product identity → commercial/platform/language → account/local ownership → retention/delete/backup → aggregate/occurrence migration → AI/public/automation boundary → metrics/SLO. Irreversible migration/deletion must follow product/data approvals plus real-data aggregate inventory.
