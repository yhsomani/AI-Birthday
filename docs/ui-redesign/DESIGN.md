# AI-Birthday Modern Executive Analytics Design System

## 1. Visual Direction & Brand Philosophy
The visual identity of AI-Birthday merges the rigor and scannability of a **modern analytics dashboard** with the **personal warmth** of celebration. The interface eliminates generic SaaS templates, floating gradients, and decorative bloat, prioritizing structured hierarchy, clean borders, high-contrast typography, and purposeful action states.

## 2. Color System
- **Background**: `#FFF9F5` (Warm Cream) / Dark Mode: `#14110F` (Warm Charcoal)
- **Primary Accent**: `#A64B2A` (Rich Terracotta Brand) / On-Primary: `#FFFFFF`
- **Primary Container**: `#FBECE6` (Soft Terracotta Tint) / On-Primary Container: `#6B2000`
- **Surface**: `#FFFFFF` / Dark Mode: `#1D1A17`
- **Surface Alt**: `#FAF0EA` / Dark Mode: `#27231F`
- **Borders & Dividers**: `#E2E8F0` / `#E9DED5` (1px solid crisp border)
- **Text Primary**: `#0F172A` / `#1E1A17`
- **Text Secondary**: `#64748B` / `#6E645C`
- **Success**: `#0F7B54` (Forest Green) / Container: `#E6F4EA`
- **Warning / Action**: `#C77700` (Warm Amber) / Container: `#FEF3C7`
- **Danger / Error**: `#B3261E` (Crimson) / Container: `#FCEDEA`

## 3. Typography
- **Primary Font**: `Inter` / System Sans-serif
- **Headline XL**: 32px / Bold / Tracking -0.02em
- **Headline LG**: 24px / Semi-bold / Tracking -0.01em
- **Body LG**: 16px / Regular / Line height 24px
- **Body MD**: 14px / Regular / Line height 20px
- **Label MD**: 12px / Semi-bold / Tracking +0.05em (Used for chips, countdown badges, and status labels)

## 4. Spacing Scale & Geometry
- **Base Grid**: 4px
- **Spacing Steps**: `xs: 4px`, `sm: 8px`, `md: 12px`, `lg: 16px`, `xl: 24px`, `xxl: 32px`
- **Corner Radii**:
  - `sm: 8px` (Buttons, inputs, chips)
  - `md: 12px` (Cards, summary tiles)
  - `lg: 16px` (Prominent callouts, dialogs, bottom sheets)
  - `pill: 999px` (Badges, countdown chips, avatar rings)
